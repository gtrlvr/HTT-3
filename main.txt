Set frame rate

Set resolution:
frame_width = 640
frame_height = 480

Calculate center of camera using resolution:
cx_C = frame_width / 2
cy_C = frame_height / 2

Set proportional gains (P controller only - I and D not needed):
Kp_x
Kp_y
    NOTE: because control is incremental (position += Kp*error each frame), the accumulation
    itself acts as an integrator, so plain P already drives steady-state error to zero.
    No I term, no D term, no dt/timing, no error memory needed.

Set deadzone (the "stop" threshold; 0 = disabled):
deadzone_x
deadzone_y

Set motor limits:
pan_min
pan_max
tilt_min
tilt_max

Set starting motor positions:
current_motor_position_pan = starting pan position
current_motor_position_tilt = starting tilt position

Set speed control (button-adjustable):
    NOTE: the Moving Speed register alone does NOT visibly change tracking speed, because
    the per-frame position jump (Kp*error) is the bottleneck, not the motor's slew rate.
    So: pin the register HIGH once, and make the speed knob a MULTIPLIER on the correction.

    moving_speed = 1023        # register pinned high so the motor can execute each step
    speed_scale = 1.0          # the real knob: multiplies correction = jump-per-frame
    speed_step = 0.25          # a/d nudge amount
    correction = Kp * error * speed_scale   # <-- this is what makes speed actually change

    A = speed up   -> speed_scale + speed_step
    D = slow down  -> speed_scale - speed_step
    1 = low    (0.5x)
    2 = medium (1.0x)
    3 = high   (2.0x)
    4 = super  (3.5x)
    q = quit

Set tracking state:
selected_track_id = none
lost_target_count = 0



Loop forever:

Open camera
```
Detect object

Detector gives bbox boxes

If detector finds nothing:
    Handle no target:
        hold current motor position
        do not calculate a correction
        selected_track_id may stay the same for a short timeout or be cleared
    go back to start of loop

Bbox boxes go into SORT

SORT outputs tracked bboxes + IDs

If SORT outputs no valid tracks:
    Handle no target:
        hold current motor position
        do not calculate a correction
        selected_track_id may stay the same for a short timeout or be cleared
    go back to start of loop

If already tracking an ID:
    Check whether selected_track_id exists in SORT output

    If selected_track_id exists:
        Use that ID's bbox

    If selected_track_id disappeared:
        Try to choose a new valid ID from SORT output

        If no valid ID can be chosen:
            Handle no target
            go back to start of loop

Else:
    Choose a valid ID from SORT output:
        choose closest bbox to camera center
        or choose largest bbox
        or choose highest-confidence bbox

    Store chosen ID as selected_track_id

Calculate center of chosen SORT bbox:

    If bbox format is x, y, w, h:
        cx_S = x + (w / 2)
        cy_S = y + (h / 2)

    If bbox format is x1, y1, x2, y2:
        cx_S = (x1 + x2) / 2
        cy_S = (y1 + y2) / 2

BODY TRACKING (original setup):
    Standard person model (yolov8n.pt), track the whole-body box center.
    BoT-SORT (default) assigns the IDs.
        cx_S = (x1 + x2) / 2
        cy_S = (y1 + y2) / 2

ID PERSISTENCE (the one change on top of default BoT-SORT):
    Use a custom BoT-SORT config (botsort_reid.yaml):
        track_buffer raised 30 -> 150   (keep lost tracks ~5s instead of ~1s)
        with_reid: True                 (re-match a reappearing person by appearance)
    Result: a person who vanishes for a second keeps their original ID.

Calculate error between SORT target center and camera center:
    error_x = cx_C - cx_S
    error_y = cy_C - cy_S

Apply deadzone to error:

    If absolute value of error_x is less than deadzone_x:
        error_x = 0

    If absolute value of error_y is less than deadzone_y:
        error_y = 0

Proportional control (P only), scaled by the live speed knob:

    correction_pan  = Kp_x * error_x * speed_scale
    correction_tilt = Kp_y * error_y * speed_scale

Calculate new motor positions:

    new_motor_position_pan = current_motor_position_pan + correction_pan
    new_motor_position_tilt = current_motor_position_tilt + correction_tilt

Clamp new motor positions:

    Clamp new_motor_position_pan between pan_min and pan_max
    Clamp new_motor_position_tilt between tilt_min and tilt_max

Send commands to motors:

    Send new_motor_position_pan to pan motor
    Send new_motor_position_tilt to tilt motor

Update stored motor positions:

    current_motor_position_pan = new_motor_position_pan
    current_motor_position_tilt = new_motor_position_tilt

Handle keyboard input each frame (OpenCV window focused):
    read key
    if key == 'a':   # speed UP
        default_speed = clamp(default_speed + speed_increment, speed_min, speed_max)
        write default_speed to pan and tilt motors
        print new speed
    if key == 'd':   # slow DOWN
        default_speed = clamp(default_speed - speed_increment, speed_min, speed_max)
        write default_speed to pan and tilt motors
        print new speed
    if key == 'q':   # quit
        break
```

End loop if keyboard interruption
